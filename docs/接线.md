# 接线

## 1. 电机与驱动

| 功能 | 引脚 | 说明 |
| --- | --- | --- |
| 左电机正转 / 反转 | PB6 / PB7 | TIM4 CH1 / CH2 |
| 右电机正转 / 反转 | PB8 / PB9 | TIM4 CH3 / CH4 |
| PWM | — | `motor_init(1000-1, 36-1)`，ARR=999，2 kHz |

> `motor.h` 里 `Speed_Max` 必须等于 999（与 ARR 一致）。写成 10000 会让 speed 一超过 999 就两轮恒 100% 占空比、**完全没有差速**，表现为"算法不转弯"。

## 2. 电感与 ADC

| 通道 | 引脚 | 用途 |
| --- | --- | --- |
| ADC 0 | PA0 | 左水平电感（主循迹） |
| ADC 1 | PA1 | 竖直电感（本版未启用） |
| ADC 2 | PA2 | 竖直电感（本版未启用） |
| ADC 3 | PA3 | 右水平电感（主循迹） |

ADC1 + DMA 循环搬运 4 通道，采样时间 239.5 周期。

运放板上多个可调电阻中，**最右侧那颗是公共增益**。工作点参考：L≈753、R≈764、不平衡度 +2%、零点 Z≈24。

## 3. OLED（0.96" 7 针 SPI，SSD1306）

| 屏上的针 | 接到 | 说明 |
| --- | --- | --- |
| GND | GND | 必须共地 |
| VCC | 3.3V（5V 亦可） | 模块带稳压 |
| D0 / SCLK | **PA5** | 时钟，上升沿采样 |
| D1 / MOSI | **PA7** | 数据，高位先出 |
| RES | **PA4** | 复位，低有效 |
| DC | **PA6** | 0=命令 1=数据 |
| CS | **GND** | 常选通 |

注意：

- **CS 必须接 GND**，接 3.3V 或悬空会"亮但不显示"。
- 7 针模块排针一般从左到右是 `GND VCC D0 D1 RES DC CS`，但厂家会调顺序，**按丝印接，不要按位置接**。
- 从 4 针 I2C 屏换过来时，`PA5/PA7` 可以复用，但 `RES/DC` 必须从 `PB0/PB1` 改到 `PA4/PA6`，否则不亮。

选 PA4~PA7 的原因：PA0~PA3 是四路电感 ADC，PB6~PB9 是电机 PWM，只有这四个脚空着且相邻。

### 排障

| 现象 | 先查 |
| --- | --- |
| 全黑 | VCC/GND；RES 是否接 PA4 |
| 亮但无字 | DC 接错或悬空；CS 没接 GND |
| 花屏乱码 | D0/D1 接反；杜邦线太长 |
| 时好时坏 | 地线只接了一根，加粗或并联 |

## 4. 供电

L298N 自带降压模块，5~12V 输入可直接降到 5V，供 C8T6、运放、OLED 使用。电池电压不用测——本版没有分压采样（STM32 内部基准只能测到 3.3V 稳压后的 VDD，测不到电池）。
